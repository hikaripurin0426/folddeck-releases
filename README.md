# FoldDeck Companion

Official desktop downloads for FoldDeck, the iPhone control deck for OBS and your computer.

**Website:** https://folddeck-official.web.app  
**Setup guide:** https://folddeck-official.web.app/guide/  
**English guide:** https://folddeck-official.web.app/en/guide/  
**Support:** info@ranranweb.com

Download published installers from the Releases section. Each release includes SHA-256 checksums and the corresponding source archives for the bundled Qt/PySide/shiboken libraries. Application code is maintained separately in a private build repository.

FoldDeck Companion uses a local-network connection. It does not require Python to be installed. Pairing QR codes contain private connection credentials; do not share them in issues or support requests.

The iPhone app's availability is listed on the official website. Companion alone does not provide an iPhone control deck.
